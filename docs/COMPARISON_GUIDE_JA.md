# PANORAMA typeGPT と typeCodex の比較

比較を公平にするには、同じMIDIイベントを両者へ入力すること。以下のデモは全12プリセットで同一MIDIフレーズと同一サンプルレート48kHzを使用している。

デモのMIDI: 48, 55, 60, 62, 67, 64, 60, 55 の順に0.66秒間隔、各音0.52秒。その後 C3/G3/C4/E4 の和音を重ねて約0.93秒。Velocityは一定ではなく周期的に変化する。

注意: **typeGPTとtypeCodexで内部アーキテクチャが異なれば、同一パッチ名でも合成内容は一致しない**。音圧差は評価に大きく影響するため、比較用にDAW側でLUFSやRMSを近づけたブラインド試聴を推奨する。

評価軸: Crystal Clarity、Algorithmic Beauty、Organic Resonance、Hybrid Uniqueness、Envelope/Musicality、CPU、Realtime Stability、GUI。
