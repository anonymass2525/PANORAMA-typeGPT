# v0.1からv0.2への比較方法

1. v0.1の01〜12とv0.2の01〜12を比較する。今回、DSPの生成結果は12件全てSHA-256一致（同じレンダラー・音声フォーマット）。
2. v0.2の13〜16を聴き、VA/FM/Ring/Resonatorの結合ごとの違いを評価する。
3. VST3をビルドして `Hybrid` エンジンへ切り替え、Routingを5種切り替える。
4. Routing Depthを0〜1まで操作し、共鳴・音量・倍音の変化を確認する。
5. Modal Stereo Widthを0〜1に動かし、モノラル互換も確認する。

比較WAVは固定MIDIフレーズを使用。音量を揃えてブラインド比較する際は別途正規化コピーを作り、原音のWAVを上書きしないこと。

## 0.2でまだないもの

任意ノード接続のGUI、サンプルレベルの汎用Graphコンパイラ、Inverse Synthesis、Sound Space、実機のCPU負荷比較。
