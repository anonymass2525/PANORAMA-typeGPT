# PANORAMA v0.3 検証結果

## DSPコードとテスト

- コンパイラー：Linux x64、GCC（CMake Release）
- CTest: 1/1合格
- 全24音色のレンダリング成功（48kHz, stereo PCM24）
- 全24音色について有限値・出力RMSの判定を自動テスト
- モジュラー音色8種のグラフトポロジーコンパイル成功
- 全8音色で配線変更がPCM波形を変更
- モジュラーノードの音量パラメーター変更がPCMを変更
- ノードが後方スロットを参照する場合の自動順序付け成功
- 循環グラフの拒否・安全な無音・修正後の音出し成功
- サンプルレート44.1k/48k/96kで複数ボイス出力が有限・正常範囲
- v0.2旧16音色の生成WAVと0.3出力WAVをSHA-256で確認：16/16一致
